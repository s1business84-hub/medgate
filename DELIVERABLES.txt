✨ KEY FEATURES
================================================================================

✅ Magic Byte Verification
   Prevents file spoofing (e.g., renaming exe to pdf)

✅ Document Hashing
   SHA-256 for tamper detection and integrity verification

✅ Type-Specific MIME Enforcement
   Enrollment letters must be PDF (no images)

✅ Configurable File Size Limits
   1 KB minimum, 25 MB maximum (configurable)

✅ Structured Error Codes
   Clients can handle errors programmatically
   Example: "FILE_TOO_LARGE", "INVALID_MIME_TYPE"

✅ Document Status Lifecycle
   pending_upload → uploaded → pending_verification → verified → expired → deleted

✅ Expiry & Renewal Tracking
   Auto-flag 30 days before expiry for renewal

✅ Auto-Delete Policy
   Raw documents deleted 30 days after verification (GDPR compliance)

✅ Rejection Handling
   9 structured rejection reasons (illegible, expired, etc.)

✅ RBAC Integration
   Permission checking: document:upload, document:verify

✅ Audit Logging
   Every validation attempt logged for compliance
