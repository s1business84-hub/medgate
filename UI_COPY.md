# UI Copy — Pilot Locked Flows

This document contains exact UI copy for the pilot. Use these strings in components and toasts.

## Student / Applicant
- Exposure acknowledgement title: "Exposure Acknowledgement"
- Exposure acknowledgement description: "I confirm I have read and understand the exposure guidance and accept responsibility for completing required precautions."
- Exposure confirmation checkbox label: "I confirm this exposure and accept responsibility"
- Start Training button (disabled tooltip when blocked): "Start Training — requires supervisor confirmation and regulatory verification"
- Start Training success toast: "Training started — your status is now In Training."
- Start Training blocked toast (missing supervisor): "Action blocked: please obtain supervisor confirmation for this student or program."
- Start Training blocked toast (missing exposure): "Action blocked: exposure acknowledgement required before starting training."

## Supervisor
- Supervisor confirmation title: "Supervisor Confirmation"
- Supervisor confirmation description: "Please confirm you will supervise this student for the listed exposures and scope."
- Supervisor confirmation success toast: "Supervisor confirmation recorded."

## Admin
- Accept action label: "Accept Application"
- Defer action label: "Defer Application"
- Decline action label: "Decline Application"
- Assign supervisor label: "Assign Supervisor"
- Assign department label: "Assign Department"
- Create EHS Allocation button: "Create EHS Allocation"
- EHS Allocation modal success toast: "EHS allocation created and student notified."

## Regulatory States
- Regulatory verified badge: "Regulatory: Verified"
- Regulatory unverified badge: "Regulatory: Unverified — action blocked"
- Regulatory admin toggle tooltip: "Toggle regulatory verification for this application. Verified applications can proceed for DHA/DoH-regulated programs."

## Generic toasts
- Generic success: "Saved successfully."
- Generic error: "An error occurred — try again or contact support."

Notes:
- Keep strings short and clear; use toasts for transient feedback and badges for persistent status.
- Use these exact strings for the pilot to keep copy consistent across pages.
